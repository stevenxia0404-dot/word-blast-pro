## Unit 4 Water 知识点梳理

### 一、核心词汇

| 英文 | 中文 |
| --- | --- |
| cloud | 云 |
| water vapour | 水蒸气 |
| rain | 雨 |
| snow | 雪 |
| lake | 湖 |
| river | 河 |
| sea | 海 |
| water drop | 水滴 |
| ice | 冰 |
| air | 空气 |
| sky | 天空 |
| lab report | 实验报告 |

### 二、句子

| 英文 | 中文 |
| --- | --- |
| In the air, I'm water vapour. | 在空气中，我是水蒸气。 |
| Little by little, I become clouds. | 渐渐地，我变成了云。 |
| I can be ice, to keep food nice. | 我可以成为冰，让食物保持美味。 |
| There are some water drops on the leaves. | 叶子上有一些水滴。 |
| Where do the water drops go? | 水滴去哪儿了？ |
| They become water vapour and go up and become the clouds in the sky. | 它们变成水蒸气升起来，变成天上的云。 |
| When it is hot, water becomes water vapour. | 天气炎热时，水会变成水蒸气。 |
| When it is cold, water vapour becomes water. | 天气寒冷时，水蒸气会凝结成水。 |
| When it is very cold, water becomes ice. | 天气非常寒冷时，水会结冰。 |
| We see water everywhere. | 我们随处可以见到水。 |

### 三、语音 s

- snow / sea / sky / so / sweet
